Почему важно: Использование метода GET для сохранения настроек нарушает стандарты REST API, а отсутствие эндпоинта чтения делает невозможным чтение настроек мобильным приложением.

Варианты: 1) Использовать GET для чтения и POST для сохранения; 2) Разделить эндпоинты по разным URL для GET (чтение) и POST/PUT (сохранение)
